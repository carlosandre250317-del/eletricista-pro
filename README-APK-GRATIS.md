# Eletricista Pro — APK grátis

Este projeto está preparado para gerar um APK Android usando GitHub Actions + Capacitor.

## Como gerar
1. Envie **todos os arquivos desta pasta** para a raiz de um repositório GitHub.
2. Confirme o commit.
3. Abra a aba **Actions**.
4. Entre em **Gerar APK - Eletricista Pro**.
5. Clique em **Run workflow**.
6. Quando terminar com ✓ verde, abra a execução.
7. No final, em **Artifacts**, baixe `eletricista-pro-apk`.
8. Extraia o ZIP e instale `app-debug.apk` no Android.

Não é necessário enviar o ZIP do projeto para dentro do repositório. Envie o conteúdo desta pasta, mantendo a pasta `.github/workflows`.
